# Проверка VocalMidi 0.3 — 22 октября 2026

В обоих режимах результат имеет длительность min(исходный вокал, конец MIDI
с учётом сдвига). Конец MIDI учитывает все дорожки, конечные паузы и изменения
темпа. В нарезке анализируется только этот интервал: более поздние фрагменты
вокала и начала нот не участвуют в проверке числа слогов. Последний фрагмент
обрезается на общем конце с коротким затуханием. Исходные файлы не меняются.

`python3 -m unittest discover -s tests -v`: 24 теста — успешно.
Среди новых проверок: вокал длиннее MIDI, MIDI длиннее вокала, одинаковая
длительность, общий сдвиг, исключение ноты ровно на конце вокала, конечная
пауза MIDI, обрезка последнего слога, сохранение PCM внутри оставленной части.
В режиме высоты проверены короткий/длинный/равный MIDI и положительный сдвиг;
сохранены проверки частоты, темпа, RMID, отмены и границы восьмисекундных блоков.
Среда тестов: Python 3.12.14, NumPy 2.3.5, mido 1.3.3, PyWORLD 0.3.5.

Android: versionCode 3, versionName 0.3, min SDK 24, target/compile SDK 35,
JDK 21.0.8, Gradle 8.13, AGP 8.9.1, Chaquopy 17.1.0.
Сборка `assembleDebug assembleDebugAndroidTest lintDebug` выполнена успешно.
Lint: 0 ошибок; сохраняются предупреждения исходного интерфейса о локализации,
значке и атрибутах новых версий Android. Подпись APK v2 проверена apksigner.
Готовый APK — debug-сборка ARM64/x86_64, подписанная тем же отладочным ключом,
что и версия 0.2 из этой рабочей среды.

Инструментальный Android-тест дополнен проверками длительности результата
для длинного и короткого MIDI и скомпилирован. На устройстве он не запускался:
аппаратное ускорение эмулятора в этой среде недоступно. Проверку реального
вокала пользователя и субъективного звучания не выполняли: аудио не приложено.

Автоматическое определение слогов по-прежнему зависит от записи. Внутри
обрабатываемого интервала несовпадение числа слогов/начал нот и слишком
короткие интервалы между нотами вызывают объяснимую ошибку. Общее окончание
файла теперь допускает обрезку. Растяжение и сжатие звука не применяются.
