# Проверка VocalMidi 0.4 — 22 октября 2026

Удалены остановки нарезки из-за несовпадения числа фрагментов и нот и из-за
непомещающегося фрагмента. Количество исходных частей адаптируется автоматически:
дополнительные разрезы распределяются по длительности, затем уточняются по
провалам огибающей; соседние части объединяются при меньшем количестве нот.
Порядок исходных частей сохраняется. При нехватке места конец части обрезается
с затуханием; оставшееся место заполняется тишиной. Растяжения и повторения нет.
Тихий звук, короткие атаки и тишина тоже проходят нарезку через резервное
разделение исходного интервала. Ошибки чтения, отмена и ограничения входных
форматов сохраняют прежнюю обработку ошибок.

`python3 -m unittest discover -s tests -v`: 31 тест — успешно.
Синтетический пример: детектор нашёл 203 фрагмента, MIDI содержит 390 начал
нот. Обработка успешно создала 390 частей и WAV нужной длительности.
Обратное соответствие проверено с сохранением исходных отсчётов и пауз между
объединёнными частями. Проверены 1, 2, 3, 7, 20, 100 нот; разбиение на
4, 7, 11, 100, 5000 частей с независимым подсчётом потреблённых отсчётов
(без повторения или потери на этапе разбиения); пустые диапазоны при числе
начал нот больше числа активных отсчётов; подрезка и затухание; note-off и
паузы; тихий звук; короткие атаки; тишина; отмена и сохранение прежнего файла.
Сохранены тесты длительности по более короткому файлу, темпа, RMID, высоты,
полифонии и границы блоков. Среда: Python 3.12.14, NumPy 2.3.5, mido 1.3.3,
PyWORLD 0.3.5. Реальная запись пользователя не была приложена: воспроизведены
указанные количества фрагментов и нот, а не само аудио.

Android: versionCode 4, versionName 0.4, min SDK 24, target/compile SDK 35,
JDK 21.0.8, Gradle 8.13, AGP 8.9.1, Chaquopy 17.1.0.
`assembleDebug assembleDebugAndroidTest lintDebug` — успешно; Lint: 0 ошибок.
Сохраняются предупреждения исходного интерфейса о локализации, значке и
атрибутах Android. Подпись APK v2 проверена; сертификат совпадает с 0.3.
APK — debug-сборка ARM64/x86_64.

Инструментальный тест Android дополнен несовпадающим количеством частей
(2 фрагмента, 3 ноты) и скомпилирован. На устройстве тест не запускался:
аппаратное ускорение эмулятора в этой среде недоступно. Субъективное качество
на реальном вокале не проверялось. Плотная сетка MIDI может резать слова и
обрезать их окончания; успешная обработка не означает сохранение всех слов
после подрезки по интервалам.
