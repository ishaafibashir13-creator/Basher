# Проверка VocalMidi 0.7 — подробная встроенная справка

Изменение: отдельный экран справки вместо краткого диалога, оглавление из
26 разделов, поиск по названиям и полному тексту, предыдущая/следующая тема.
Открытие оглавления с главного экрана, отдельная кнопка первого запуска вверху
и прямой переход к ручной нарезке из редактора. Справка встроена в APK,
доступ к интернету не требуется.

Материал: 239 абзацев, около 7400 слов. Объяснены базовые термины без
предположения музыкальной подготовки. Есть первый запуск, выбор файлов,
все режимы, сдвиг и длительность, назначение четырёх ручных границ,
пошаговый числовой пример, прослушивание, разделение, тюнинг, сохранение,
TalkBack, разбор ошибок и ограничения.

## Выполнено

- `assembleDebug assembleDebugAndroidTest lintDebug` — успешно. Lint не
  обнаружил ошибок; предупреждения доступны в отчёте сборки.
- Проверена структура встроенного JSON: 26 уникальных идентификаторов,
  последовательная нумерация тем, непустое содержание и существование тем
  `quickstart` и `manual`, на которые ведут прямые переходы.
- USER_GUIDE.md совпадает с текстом встроенных разделов.
- Проверены числа учебного примера при 120 BPM: доли 1–7 означают
  0–3 секунды, доли 7–10 — 3–4,5 секунды; интервалы не перекрываются.
- APK проверяется apksigner, номер версии увеличен до 7 (0.7), сертификат
  сравнивается с 0.6 для установки обновления поверх предыдущей сборки.
- При упаковке проверяется наличие в APK справки, всех её 26 тем,
  HelpActivity в манифесте и исходников экрана в архиве.

Поля поиска связаны с текстовой подписью, кнопки имеют минимум 56 dp,
высота элементов не фиксирована и может расти при увеличении шрифта.
Текст разбит на отдельные абзацы. Заголовки отмечены для доступности на
Android 9+, число результатов поиска имеет polite live region. При переходе
между темами экран прокручивается к началу, доступный фокус переводится на
заголовок. Сохраняются тема, запрос и положение при пересоздании Activity.

## Границы проверки

Установки на физический телефон, проверки TalkBack, работы экранной
клавиатуры и навигации на устройстве в этой среде не было. Инструментальная
тестовая APK собрана, но не запущена: нет подключённого устройства или
аппаратно ускоряемого эмулятора.

Алгоритмы аудио, MIDI и формат ручной разметки не изменялись.
Аудиотесты для этого изменения справки повторно не запускались; предыдущая
проверка DSP (41 тест) описана в VALIDATION-0.6.md. Справка не обещает
идеального качества для произвольных файлов и объясняет реальные ограничения.
