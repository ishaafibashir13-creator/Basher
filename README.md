Результат в обоих режимах ограничен более коротким файлом:

- вокал длиннее MIDI — лишняя часть вокала обрезается;
- MIDI длиннее вокала — ноты за концом исходного вокала не обрабатываются,
  результат не удлиняется;
- одинаковая длительность — результат сохраняет эту длительность.

Длительность MIDI считается до конца файла, включая конечные паузы и изменения
темпа. Общий сдвиг MIDI сдвигает и его конец; результат в любом случае не
выходит за длительность исходного вокала. На границе обрезки звук получает
короткое затухание. Исходные загруженные файлы остаются целыми: обрезается
только выходной WAV.

Режим по умолчанию: **«Нарезка под ритм — естественная скорость»**.
Выберите чистый одиночный вокал, MIDI и дорожку, затем нажмите «Обработать вокал».
Прослушайте результат и сохраните WAV. Интернет для обработки не нужен.

Нарезка определяет фрагменты по огибающей громкости: паузы и глубокие провалы
между слогами. Фрагменты последовательно переносятся на начала нот, без
ресэмплинга, растяжения, сжатия, повторения или изменения высоты. Внутри
сохраняемой части фрагмента PCM сохраняется побитно; только первые/последние 8 мс плавно затухают.
Позиции назначения округляются до ближайшего отсчёта 32 кГц. Распознавание
начала слога приблизительное: анализ 5 мс, до 10 мс запаса для тихих согласных.
Это не распознавание текста или фонем: идеальное определение границ и
естественность на любой записи гарантировать нельзя.

Один обнаруженный фрагмент соответствует одному началу ноты; одновременно
начавшиеся ноты аккорда считаются одним событием. Изменения темпа MIDI учитываются.
При несовпадении числа фрагментов и начал нот внутри общего интервала
приложение показывает оба числа и предлагает
изменить чувствительность или дорожку. Внутри этого интервала оно не удаляет и не повторяет слоги.
Последний фрагмент обрезается на границе общей длительности.
Если слог длиннее внутреннего интервала до следующей ноты, обработка останавливается:
невозможно сохранить его целиком и естественную скорость в более коротком
интервале. Используйте MIDI с более медленным темпом. Последний успешный
результат сохраняется при ошибке/отмене.

Параметры:
- «Меньше разрезов» понижает порог тишины для тихих частей голоса.
- «Больше разрезов» повышает порог; результат зависит от записи.
- Сдвиг задерживает всю сетку MIDI; отрицательные начала в нарезке запрещены.
- «Заглушать вокал в паузах MIDI» требует, чтобы слог поместился до
  note-off внутри обрабатываемого интервала. На общем конце допускается обрезка. Без этой опции естественный хвост может продолжаться в паузе,
  но не за начало следующей ноты. Короткие фрагменты дополняются тишиной,
  а не растягиваются до длительности ноты.
- Транспозиция и правило выбора высоты влияют на MIDI-прослушивание и старый
  режим высоты, но не меняют звук в нарезке.

Режим «Высота по MIDI — прежний ритм» сохраняет прежнюю обработку PyWORLD.

# Вокал и MIDI — Android, версия 0.1

Приложение для Башира: локальная коррекция высоты одиночного вокала по выбранной MIDI-дорожке. Использует **настоящий PyWORLD 0.3.5**, собранный из исходников под Android, а не сетевой сервис и не имитацию обработки.

## Установка

Откройте `VocalMidi-0.1.apk` на 64-битном Android 7.0 или новее и разрешите установку из выбранного источника, если Android попросит. APK подписан отладочным ключом: это проверяемая предварительная версия для личного использования, не релиз Google Play. Поддержаны ARM64 и x86_64. ARM32 не поддержан. Перед обновлением с другим ключом Android может потребовать удаление предыдущей версии; сначала экспортируйте результат.

## Использование с TalkBack

1. Кнопкой «Выбрать исходный вокал» откройте файл через системный проводник. Фильтр показывает все типы файлов, чтобы не скрывать файлы с необычным расширением.
2. Выберите MIDI. В списке «Дорожка MIDI» указаны номер, имя, количество нот и длительность.
3. Выберите правило для аккордов: самая высокая, самая низкая или последняя начавшаяся нота. Ударный канал исключён.
4. Прослушайте выбранную мелодию. Тембр простой синтезированный; звучит именно мелодия, выбранная для обработки, с учётом транспозиции.
5. При необходимости задайте сдвиг MIDI: положительное число задерживает ноты относительно исходного вокала. Транспозиция — целое число от −24 до 24 полутонов.
6. Запустите подгонку. Состояние и прогресс доступны для озвучивания. Обработка продолжится при сворачивании, пока Android не остановит процесс. Отмена проверяется между восьмисекундными фрагментами, поэтому может сработать с задержкой.
7. Прослушайте последний результат и сохраните его как WAV через системный диалог.

Есть отдельные кнопки паузы, остановки и перемотки на 10 секунд. При уходе с экрана воспроизведение останавливается. Интерфейс не требует жестов по графику или точного попадания на ноты: стандартные кнопки, подписанные поля и списки, масштабируемый текст и прокрутка. Это проектирование для доступности, **не гарантия идеальной совместимости со всеми версиями TalkBack**. Нужна проверка с незрячим пользователем на реальном телефоне.

## Что именно делает алгоритм

FFmpeg декодирует первый аудиопоток в моно PCM16, 32 кГц. Расширение входного файла не определяет формат. При неудаче автоматического определения выполняется дополнительная попытка чтения как MP3. После импорта исходный контейнер удаляется из рабочей копии приложения; оригинал пользователя не изменяется.

PyWORLD выполняет Harvest → StoneMask → CheapTrick → D4C → synthesis. На звучащих участках F0 заменяется частотой текущей MIDI-ноты; спектральная огибающая и апериодическая составляющая сохраняются. Глухие согласные, дыхание и тишина не превращаются в периодический тон. В паузах MIDI по умолчанию остаётся исходная высота; опция позволяет заглушить эти участки. Блоки по 8 секунд используют контекст 200 мс с каждого края и перекрёстное затухание, чтобы ограничить память и снизить швы.

MIDI type 0/1, карта темпа по всем дорожкам, note-off и note-on с нулевой velocity, а также RIFF RMID поддерживаются. В аккордах выбирается одна нота по заданному правилу. Педаль sustain, pitch bend, инструменты и динамика MIDI не моделируются. Type 2 и SMPTE отклоняются с сообщением.

## Существенные ограничения

- **Не обещает идеального звучания.** Сильный перенос высоты, хрип, шум, несколько голосов, реверберация и музыка в исходнике дают артефакты. Разделения голоса и инструментов нет.
- **Не переставляет слоги и не выравнивает ритм автоматически.** Вокал и MIDI должны уже совпадать по времени, кроме настраиваемого общего сдвига. Длительность сохраняется. Для отдельного автоматического выравнивания фраз нужен дополнительный алгоритм и реальные примеры.
- **Не поддерживает абсолютно все файлы.** Ограничено демультиплексорами и декодерами включённого FFmpeg; DRM, сильно повреждённые и неизвестные контейнеры могут не открыться. Выбирается первый аудиопоток.
- Вход: до 512 МБ и до 10 минут. MIDI: до 8 МБ, до 10 минут. Выход: моно WAV PCM16 32 кГц. Ноты обработки: 40–2000 Гц после транспозиции; вне диапазона предлагается изменить параметры. Анализ исходного F0: 50–1100 Гц.
- Это предварительная сборка. Реальное ARM64-устройство, TalkBack и Android с 16-КБ страницами памяти не проверены. Старые зависимости NumPy/OpenBLAS могут потребовать обновления для отдельных устройств с 16-КБ страницами.
- Принудительная остановка или уничтожение процесса Android прерывает задачу; автоматического возобновления нет. Повторный запуск возможен с сохранёнными исходниками.

## Приватность

Разрешение INTERNET удалено из объединённого manifest. Записи не отправляются на сервер. Выбор и экспорт используют Storage Access Framework, доступа ко всему хранилищу нет. Локальные рабочие файлы находятся в приватном каталоге приложения; резервное копирование выключено. Удаление приложения удаляет рабочие копии, но не экспортированные файлы.

## Сборка APK из исходников

Нужны JDK 17, Android SDK Platform 35 и Build Tools 35.0.0, Python 3.12 на машине сборки. Gradle Wrapper 8.13 включён. Android Gradle Plugin 8.9.1, Chaquopy 17.1.0. FFmpegKit также требует явно указанную Java-зависимость smart-exception-java 0.2.1. Интернет требуется только на машине сборки для получения зависимостей.

```bash
export ANDROID_HOME=/path/to/android-sdk
export JAVA_HOME=/path/to/jdk-17
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

В Windows используйте `gradlew.bat`. Готовые Android wheels PyWORLD лежат в `vendor/`; NDK для обычной пересборки APK не нужен. Если Python 3.12 не найден автоматически, укажите `buildPython` в блоке `chaquopy.defaultConfig` файла `app/build.gradle`.

Для production-сборки добавьте собственную конфигурацию signingConfig и защитите ключ. Отладочный ключ в архив исходников не включён.

## Пересборка PyWORLD

Полные исходники PyWORLD и WORLD включены в `vendor/pyworld-0.3.5/`. Единственное изменение обёртки в wheel: `__init__.py` импортирует расширение и задаёт версию напрямую, без зависимости от устаревшего `pkg_resources`. Сгенерированный Cython C++ включён. Генератор: Cython 3.0.12, заголовки/pxd NumPy 1.26.x. Не генерируйте C++ с NumPy 2.x для этой сборки.

1. Установите NDK 27.2.12479018 на Linux x86_64.
2. Для каждой ABI распакуйте архив CPython Chaquopy `com.chaquo.python:target:3.12.15-0` (`target-3.12.15-0-arm64-v8a.zip` / `target-3.12.15-0-x86_64.zip`) из Maven Central.
3. Распакуйте соответствующий wheel NumPy 1.26.2 cp312 из `https://chaquo.com/pypi-13.1/numpy/`.
4. Выполните:

```bash
python build_pyworld.py --ndk /path/to/ndk \
  --python-target /path/to/unpacked-cpython \
  --numpy-target /path/to/unpacked-numpy --abi arm64-v8a
# Повторить с x86_64 и соответствующими архивами.
```

Скрипт использует статическую стандартную библиотеку C++ и выравнивание 16 КБ для самого PyWORLD. Это не означает, что все сторонние библиотеки поддерживают 16-КБ страницы.

## Проверки

```bash
python -m pip install numpy mido==1.3.3 pyworld==0.3.5 'setuptools<81'
python -m unittest discover -s tests -v
./gradlew connectedDebugAndroidTest
```

Семь модульных проверок: глобальная карта темпа, аккорды/сдвиг/транспозиция, RIFF MIDI, отказ для type 2, частота прослушивания, перенос тестового сигнала с 220 на 440 Гц с точной длительностью на стыке блоков, отмена. ## Структура и лицензии

- `app/src/main/java/` — нативный интерфейс, импорт/экспорт, проигрыватель, фоновая служба.
- `app/src/main/python/engine.py` — чтение MIDI, синтез прослушивания и обработка PyWORLD.
- `tests/` и `app/src/androidTest/` — проверки.
- `vendor/` — Android wheels, исходники и лицензии PyWORLD/WORLD.

- Chaquopy — MIT; NumPy — BSD; Mido — MIT.

Исходники, инструкции сборки и лицензии: https://github.com/ffmpegkit-maintained/ffmpeg и https://github.com/ffmpegkit-maintained/ffmpeg/releases. При распространении учитывайте лицензии конкретных включённых библиотек. APK с отладочной подписью и полный проект позволяют заменять и пересобирать зависимости.
