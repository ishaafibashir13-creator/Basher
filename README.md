В версии 0.5 прежняя обрезка отдельных фрагментов заменена встроенной
[Rubber Band Library 4.0.0](https://breakfastquay.com/rubberband/) с движком
**R3/Finer**. Это непрерывное растяжение и сжатие времени с сохранением высоты,
а не независимое воспроизведение коротких обрезков. Устанавливать библиотеку
отдельно на телефон не требуется; интернет для обработки не нужен.

## Как пользоваться

1. Выберите чистый одиночный вокал и MIDI.
2. Выберите дорожку и послушайте MIDI.
3. Выберите **«Нарезка и ритм, затем тюнинг MIDI»** для обоих этапов либо отдельный режим ритма/высоты.
4. При необходимости задайте сдвиг MIDI. Положительный сдвиг задерживает ноты.
5. Включите **«Соблюдать паузы MIDI»**, если нужны именно паузы между нотами.
6. Нажмите «Обработать вокал», прослушайте и сохраните WAV.

Соседние легато-ноты образуют непрерывный участок: на каждой новой ноте не
создаются искусственные провалы громкости. При включённой опции пауз только
настоящие промежутки MIDI заглушаются с короткими плавными краями.

В объединённом режиме сначала Rubber Band R3 меняет время вокала, затем
PyWORLD настраивает уже выровненный голос под MIDI. Переимпортировать WAV
между этапами не нужно. Транспозиция применяется на втором этапе.
Сдвиг MIDI один и тот же на обоих этапах и не перемещает звук повторно.
При отмене любого этапа предыдущий результат сохраняется.

## Ручная нарезка для TalkBack

1. Выберите исходники, дорожку и сдвиг, откройте **«Ручная нарезка и выравнивание — редактор для TalkBack»**.
2. При первом открытии создаётся один фрагмент всей записи. Поля начала и конца исходника задаются в секундах.
3. Прослушайте его, поставьте на паузу, уточните позицию кнопками ±0,1/1 секунды и отметьте границу или нажмите **«Разделить фрагмент в позиции прослушивания»**. Границы также редактируются числом и кнопками ±10 мс.
4. Задайте начальную/конечную долю MIDI. **Доля 1 — начало MIDI; одна доля всегда четвертная нота**, независимо от размера. Например, при 120 BPM доля 2 соответствует 0,5 с MIDI, доля 2,5 — 0,75 с. Сдвиг прибавляется отдельно. Это сквозные доли, не номер такта.
5. Выберите шаг четверть, восьмая или шестнадцатая. Передвигайте фрагмент по сетке, меняйте конец либо привяжите обе границы. Изменения BPM MIDI учитываются точно по карте темпа.
6. Прослушайте исходный или выровненный фрагмент. Метроном в выровненном прослушивании отбивает четвертные доли MIDI; его можно выключить. В итоговый WAV метроном не добавляется.
7. Сохраните разметку и вернитесь. Выберите режим ритма либо объединённый режим, включите ручную разметку и обработайте вокал.

В редакторе нет обязательной волны, перетаскивания или действий, доступных
только зрительно. Поля связаны с подписями через `labelFor`, кнопки не меньше
56 dp, сообщения об операциях имеют polite live region. Можно слушать окрестность
каждой границы и отменять последнее изменение. Разметка сохраняется локально,
включая выбранный фрагмент и шаг. Новый успешный импорт вокала или MIDI сбрасывает
прежнюю разметку. При другом сдвиге границы проверяются заново.

Ручные фрагменты растягиваются независимо, с короткими краями против щелчков.
Начало/конец MIDI определяют место и длительность каждого фрагмента; между
фрагментами остаётся тишина. Исходные участки можно использовать повторно или
переставлять, но целевые интервалы не должны перекрываться. Неуказанные участки
не включаются. Всего до 2000 фрагментов, каждый не короче 10 мс; границы результата
ограничены более коротким файлом. Начальный фрагмент всей записи можно разделить
или укоротить, чтобы освободить место для новых. В режиме только высоты ручная
разметка не применяется. Кнопка сохранения объясняет ошибки границ и перекрытия.

Работа с TalkBack на физическом телефоне в этой среде **не проверена**.
Инструментальный тест подписей и сохранения включён в исходники и собирается,
но требует устройства для запуска.

## Выравнивание вокала

Атаки и паузы определяются по громкости. Устойчивые изменения высоты исходного
голоса помогают обнаружить границы спетых событий. **Высоты исходного вокала
и MIDI не сравниваются**: MIDI может содержать совершенно другую мелодию.
Сопоставление идёт по порядку, паузам, относительному времени и длительностям.

Разное число вокальных событий и нот допускается. Одна фраза/гласная может
занимать несколько нот, несколько событий могут попадать в одну ноту.
Количество не подгоняется принудительными разрезами и повторениями. Из
сопоставления строится монотонная карта времени в отсчётах; Rubber Band
сначала анализирует материал, затем непрерывно обрабатывает его по этой карте.
Вторая стадия использует блоки 256 отсчётов / 8 мс для своевременного
обновления локального темпа. Окончания фраз растягиваются или сжимаются.

Выходной WAV по-прежнему ограничен более коротким файлом. Конец MIDI
учитывает конечные паузы, изменения темпа и заданный сдвиг. Если последняя
фраза начинается до общей границы, её окончание берётся целиком и сжимается
в последний доступный интервал — не отсекается перед обработкой. Более поздние
фразы за общей границей не включаются. Исходные файлы сохраняются целиком.

Обработка идёт по моно PCM16 32 кГц, до 10 минут. Импорт аудио — FFmpeg,
исходный файл до 512 МБ. MIDI: тип 0/1 и RIFF RMID, до 8 МБ; ударный канал
исключён. При аккордах используется выбранное правило высокой/низкой/последней
ноты. Педаль, pitch bend, MIDI типа 2 и SMPTE не поддерживаются.

Сильные изменения длительности и автоматические ошибки определения атак
могут давать артефакты. Автоматический режим не распознаёт текст:
идеальное соответствие произвольной записи и произвольного MIDI не обещается.
Громкость нормируется только при угрозе клиппинга. Последний успешный результат
сохраняется при ошибке или отмене. Обработка работает в фоновом сервисе,
а элементы интерфейса имеют текстовые подписи для TalkBack.

## Сборка

Android 7.0+, ARM64 или x86_64. Нужны Java 17/21, Android SDK 35 и Python 3.12.
Укажите путь `sdk.dir` в локальном `local.properties`, затем:

    ./gradlew assembleDebug assembleDebugAndroidTest lintDebug

APK: `app/build/outputs/apk/debug/app-debug.apk`. Предоставленный APK —
устанавливаемая debug-сборка; версии 0.2–0.6 из этой рабочей среды подписаны
одним сертификатом и имеют возрастающий versionCode. Для публикации
собственного release используйте собственный ключ.

Python/Android-зависимости включены в `vendor`: NumPy, mido, packaging,
PyWORLD, libc++ и адаптер Rubber Band. Pip при сборке использует локальные
wheels с `--no-index`. Gradle и Android-зависимости загружаются из Maven/Google.
Обычная сборка APK не требует NDK: нативные wheels уже включены.

Пересборка Rubber Band для Android/host: [инструкция](build-support/rubberband/README.md).
Исходники библиотеки — `vendor/rubberband-4.0.0`, адаптер —
`native/rubberband_module.cpp`, скрипт — `build_rubberband.py`.
Рецепт NumPy: `build-support/numpy/README.md`; PyWORLD: `build_pyworld.py`.

## Проверка

Для тестов с настоящей библиотекой на Linux (g++, заголовки Python 3.12):

    python3 build_rubberband.py --host
    pip install numpy mido pyworld 'setuptools<81'
    PYTHONPATH=native-build/host python3 -m unittest discover -s tests -v

Проверяются слышимые атаки по огибающей выходного WAV, частоты по FFT,
сжатие/растяжение 0.5× и 2×, сохранение окончания, паузы, легато без тремоло,
другая мелодия MIDI, 203/390 событий и ограничение длительности.
Новые проверки ручного редактора и объединённого режима: [VALIDATION-0.6.md](VALIDATION-0.6.md).
Измерения автоматического R3: [VALIDATION-0.5.md](VALIDATION-0.5.md).
Инструментальная проверка Android: `./gradlew connectedDebugAndroidTest`
с подключённым устройством или аппаратно ускоряемым эмулятором.
